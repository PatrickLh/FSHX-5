# 风色幻想 5 原始资源

原始资源提取已完成，专有格式解码和引用缺口仍单独记录。最新统计与边界见 `../docs/resource-extraction-completion.md`。

- `source/`：原始游戏分发文件、归档及程序，保留原件。
- `unpacked_verified_v1/`：恢复原名的完整文件；`__versions__` 保留历史版本。
- `organized/`：人物、背景、动效、模型、UI、音频、故事与辅助文件；HTML 为预览入口。
- `manifests/`：资源目录、来源哈希、提取验证、结构索引和未解决问题。
- `unpacked/`：早期流级输出，保留追溯，不作为完整文件入口。

不根据同名候选自动替换缺图，不修改原始颜色和透明规则。人物三维制作及 Godot 重建暂不推进。
