# 风色幻想 5 资源提取与 Godot 重建计划

更新日期：2026-10-30

## 目标与边界

先完整保存原游戏资源，整理人物、背景、图标、人物动画及技能动效，并保留已拆分的故事；之后建立 Godot 工程，逐步重建人物、技能与场景。

当前 source 是游戏发行文件，不是完整引擎源码。资源包解压、资源名称恢复和 Godot 演出重建分别验收；不以“图片能打开”作为动画已还原的依据。不承诺全部原名、加密数据或三维骨骼能够恢复。二维帧可作建模参考，不能自动等价为完整三维模型。

## 当前目录与迁移

```text
original_resources/
  source/                     原 origin：压缩包、游戏本体，保持原内容
  unpacked/                   原 extracted：现有解包流，暂不删除或去重
  organized/
    characters/               人物立绘、表情、动作帧、动画描述
    backgrounds/              对话背景、过场图、场景图片
    effects/                  技能动画、粒子、特效贴图、演出配置
    models/                   原始模型与关联贴图
    ui/                       图标、界面图片、技能名牌
    audio/                    音乐、音效及技能音效引用
    story/                    原 story，保留已有拆分与分析文件
    legacy_assets/            原 assets，历史整理说明，待核验
  manifests/                  来源、校验、映射、缺口和迁移记录
godot/                        后续 Godot 工程及实际使用的转换资源
tools/                        解包、分析、导出、校验脚本
docs/                         本计划与分析文档
```

迁移时检查到：source 约 1.5 GB；unpacked 约 1.9 GB；story 约 53 MB。历史 assets 实际仅有 README，不能将其中所述立绘、模型等视为现有导出成果。精确迁移前后文件数和总字节数记录在 `original_resources/manifests/directory_migration.json`。

脚本路径已随迁移调整，从仓库根目录运行。现有脚本仍可能缺少历史中间数据；路径更新不表示管线已能完整执行。`.gitignore` 保留原先对原始包、解包流及 tools 的忽略策略，新增 Godot 缓存忽略；旧工具继续保留原忽略策略；本轮新增 `tools/resource_pipeline/` 已取消忽略，以便纳入版本控制。生成的大体积素材与缓存排除在版本控制之外。

当前主要不确定项：历史导出成果缺失、解包重复、部分图像格式未知、无名流的归属、动画和演出参数、wrap 数据格式。每个问题记录证据、影响范围与下一步处理方式，不通过猜测掩盖缺口。暂不删除旧解包数据，不自动执行历史中会覆盖故事成果的脚本。
