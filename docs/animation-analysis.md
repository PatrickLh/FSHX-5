# 人物动画与技能脚本：第二轮分析

日期：2026-10-29

> 后续已补充粒子、材质序列与基础攻击组合实验，最新引用口径见 [第三轮报告](resource-linkage-analysis.md)。

## 本轮结果

全部 6,573 份 ANT 已完成结构解析，得到 45,204 帧、61,361 个图层。帧数与源文件声明一致，119,711 个非空源文本行全部被计入，没有通过丢弃未知行来让解析通过。

750 行未匹配图片引用已降为 **183 行（56 个不同路径）**。解决的 567 行仅去除了 `ANITEXTURE/` 或 `BMP/` 旧制作根前缀，剩余路径必须与包内文件精确一致；没有进行相似名字替换。

747 份 BattleScript 已全部解析为嵌套节点，得到 30,763 个带 Type 的节点，274,981 个属性均保留。节点既包括演出动作，也包括资源声明，不能将 30,763 当作实际执行动作数量。

## 动画格式及保留字段

每份 ANT 包含：

1. 声明帧数与四个全局原始字段。
2. 每帧九列头部：时间原值、两个事件原值、声音引用、图层数、三个向量分量和边界原值。
3. 每个图层二十列：图片引用、原始标志、九个矩阵分量、三个平移分量、五个渲染字段和颜色十六进制值。

帧可以有零个或多个图层；实际数据最多观察到 30 层。5,612 帧带有音效引用，全部已按路径找到对应散装音频，并纳入演出依赖遍历；预览不会自动播放声音。

对配套 ANI 的资源表，目前 6,545 份能解析，27 份缺少同名配套文件，1 份（`man/0121/15b.ant` 的 ANI 配套文件）在资源字符串读取时失败。ANT 本身仍可完整解析。失败记录保留于 unresolved.json。

ANI 中记录的资源尺寸与导出贴图像素尺寸可能不同：例如头像资源可以保留原编辑尺寸，而图片只有其一半。本轮保存两套尺寸，不以不相等直接判断图片损坏。结构文件共记录 34,971 次资源尺寸对照；预览使用 ANI 资源尺寸作为布局假设，仍需与游戏运行画面核验。

对单图层、无旋转/错切且有资源尺寸的样本，32,369 帧中有 30,876 帧的边界原值与变换后半对角线相符（误差小于 0.001）。这支持上述字段解释，但不是所有帧的几何或引擎渲染语义证明。

## 可检查的预览

入口：`original_resources/organized/animation_viewer.html`。提供人物待机、移动、攻击、头像叠层及技能特效样本，共 26 个不同动画，支持播放、暂停、逐帧、拖动进度和调整试播速率。

预览会显示源路径、源行号、每层引用、矩阵、平移、颜色和渲染原值。纯绿色抠除与加亮合成均为可切换的预览选项，不改变原始 PNG。选择框的动作名称来自 PersonPoseList。

明确的预览边界：

- 默认按 1000 个原始时间单位/秒试播，尚未在原游戏验证时间单位。
- 显示 XY 仿射变换，保留 Z 数据，但没有原游戏三维投影、镜头和深度遮挡。
- 颜色按通道相乘、alpha 试绘，原引擎混合枚举、采样和 billboarding 尚未完整映射。
- 特效预览是独立 ANT 片段；不是包含人物、镜头、粒子和音效的完整技能演出。
- 浏览器通过 file:// 打开时可能限制像素读取；如需绿色抠除与颜色试绘，可用本地 HTTP 服务打开。

本轮已经在浏览器检查人物显示、播放/暂停、下一帧、动画切换、绿色预览抠除以及两图层特效的参数显示。

## 技能脚本与依赖

每份脚本输出节点树、父子关系、源码行号、原始属性、资源声明、Type 节点、递归可达资源与缺失依赖。保留条件触发关系；`fDelayTime` 和 `fWorkTime` 仍为每个节点的原值，不因节点嵌套而擅自相加成绝对时间。

原脚本中存在嵌套方括号和额外右括号的节点标题，解析器按整行标题保留名称；没有改写原脚本。

已生成三份具体核验档案：

- [attack00](skill-reviews/attack00.md)：基础攻击脚本。
- [common0065](skill-reviews/common0065.md)：包含动画、粒子或其他演出对象的依赖与触发节点。
- [s1014](skill-reviews/s1014.md)：较复杂演出脚本的资源、条件和动作原值。

文件名没有直接等同为游戏中文技能名。完整结构位于 `original_resources/organized/effects/script_data/BattleScript/`。
